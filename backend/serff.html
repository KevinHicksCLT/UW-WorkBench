SERFF HOME

SERFF Filing Access (SFA) is now in production for an increasing number of states. This new interface provides consumers and other interested parties the ability to access Rate and Form Filings via the Internet that the participating state has marked available.

SFA also provides access to Health Plan Binder information which has been marked public by the state.

The states in blue below are currently using SFA and have chosen to post their state website link here. Other states not marked below may also be in production but have not yet provided state website information for this SERFF page. To access a state's SFA page or learn more about its public access information, click on the state below.

For more information for the Insurance Compact Commission’s participation in SERFF Filing Access, please click here.

If you have any questions on how to use SFA, please feel free to email sfahelp@naic.org or call (816) 783-8990.
