Operating-Model ERD — branch v3 (complete application schema)

Single complete ERD for all application tables. People/Capacity removed. Nothing parked — Initiative, Metric, KnowledgeBase, AgentSkill all included. 34 tables; every table has a PK and all FKs.
Companion: ERD_branch_v3.flow.html (build-sequence roadmap).
Two generic spines. Org: Company → OrgLevelType(1..N) → OrgUnit (recursive tree) → Role — add/rename levels as data; Role at multiple levels via RoleOrgAssignment, reports via managerRoleId. Value stream: recursive ProcessNode typed by ProcessLevelType (Value Stream = node at L2; isTask = Task). Connections: Node* junctions hold a single FK to ProcessNode → bind at any level. Unparked: Initiative (+NodeInitiative), Metric, KnowledgeBase, AgentSkill. Boundary: ExternalParty/ExternalInteraction capture wait-time on parties you don't control.
Keys: every entity = surrogate id PK (junctions too); *Closure tables = composite PK,FK on (ancestor, descendant). Association rule: 1:N = FK column on child; M:N / attributed link = junction table (still just FKs).
Naming: dbValue = system/generic name (stable) · displayValue = admin-editable label, overridable per company via Terminology.
Color key: connection / junction tables value stream org work / control everything else   (closures are link tables → red)
